WORKLINK — LANDING PAGE

Archivos:
- index.html: página principal.
- worklink.png: coloca aquí tu logotipo. Debe estar en la misma carpeta que index.html.

Antes de publicar:
1. Abre index.html con Visual Studio Code.
2. Busca el objeto ENLACES al final del archivo.
3. Sustituye los enlaces de Instagram, Facebook y TikTok por los enlaces reales.
4. Comprueba que la dirección de la plataforma sea la correcta.
5. Abre index.html en el navegador para probarlo.

Para GitHub Pages:
- Sube index.html y worklink.png a la raíz del repositorio.
- Activa GitHub Pages desde Settings > Pages.
- Usa la URL pública de GitHub Pages para generar el QR de las tarjetas.
